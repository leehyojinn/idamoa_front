공간기획 프로그램 사용법

3단계로 간편하게 공간을 기획하세요

1

평면도 업로드

JPG 도면 업로드

파일 업로드 버튼을 클릭하여 JPG 형식의 평면도를 업로드하세요.

지원 형식

JPG, JPEG, PNG

최대 크기

10MB

2

스케일 설정

4개 포인트 클릭으로 축척 계산

도면 위에서 기준점을 클릭하고 실제 치수를 입력하면 자동으로 축척이 설정됩니다.

클릭 순서

1 첫 번째 기준점 클릭
2 두 번째 기준점 클릭
3 세 번째 기준점 클릭
4 네 번째 기준점 클릭

치수 입력

1-2점 거리의 실제 치수

예: 4200mm

3-4점 거리의 실제 치수

예: 2800mm

✓ 자동으로 축척 계산 → "스케일 적용됨" 표시

3

룸 템플릿 활용 기획

좌측: 룸 템플릿활용 공간구획

다양한 룸 템플릿을 선택하여 드래그로 배치하고 속성을 수정하세요.

사용방법

1 좌측에서 원하는 룸 템플릿 선택
2 배치할 공간을 드래그하여 위치 선정
3 속성수정 사용하여 완성
